# Student Attendance System

A static frontend prototype for managing student attendance, campus events, and sanctions.

## Structure

- `index.html` is the entry page.
- `pages/` contains role-specific screens.
- `pages/login.html` is the login page.
- `pages/kiosk.html` is the organizer-controlled hardware scanner screen.
- `pages/ssc-dashboard.html` is the SSC dashboard.
- `pages/ssc-manage-biometric.html` is the SSC fingerprint enrollment screen.
- `pages/ssc-biometric-audit.html` is the SSC enrollment audit log.
- `pages/ssc-manage-events.html` is the SSC event management page.
- `pages/ssc-manage-officers.html` is the SSC officer management page.
- `pages/ssc-manage-sanctions.html` is the SSC sanctions management page.
- `pages/ssc-manage-students.html` is the SSC student management page.
- `pages/ssc-reports.html` is the SSC reports page.
- `pages/student-dashboard.html` is the student dashboard.
- `pages/student-attendance.html` is the student attendance page.
- `pages/student-appeal.html` is the student appeal page.
- `pages/student-profile.html` is the student profile page.
- `pages/student-sanctions.html` is the student sanctions page.
- `css/` contains all stylesheets.
- `css/variables.css` contains CSS custom properties.
- `css/reset.css` contains CSS reset rules.
- `css/styles.css` contains shared styles.
- `css/auth.css` contains authentication/login styles.
- `css/layout.css` contains layout styles.
- `css/role-dashboard.css` contains role dashboard styles.
- `css/student-dashboard.css` contains student dashboard styles.
- `css/kiosk.css` contains kiosk styles.
- `css/dark-style.css` contains dark theme styles.
- `js/` contains JavaScript modules.
- `js/data.js` contains sample data.
- `js/auth.js` contains authentication logic.
- `js/ui.js` contains UI utilities.
- `js/admin.js` contains admin functions.
- `js/student.js` contains student functions.
- `js/organizer.js` contains organizer functions.
- `js/kiosk.js` contains kiosk functions.
- `js/fingerprint-scanner.js` contains fingerprint scanner simulation.
- `images/` contains image assets.

Open `index.html` in a browser to start.
