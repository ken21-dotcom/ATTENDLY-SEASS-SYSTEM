# Student Attendance System

A static frontend prototype for managing student attendance, campus events, and sanctions.

## Structure

- `index.html` is the entry page.
- `pages/` contains role-specific screens.
- `pages/kiosk.html` is the organizer-controlled hardware scanner screen.
- `pages/admin-manage-biometric.html` is the admin fingerprint enrollment screen.
- `pages/admin-biometric-audit.html` is the admin enrollment audit log.
- `css/styles.css` contains shared styles.
- `js/` contains shared data, authentication, UI, role, kiosk, and biometric modules.

Open `index.html` in a browser to start.
